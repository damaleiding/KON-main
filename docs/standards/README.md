# 工程规范入口

`docs/standards/` 保存跨项目长期有效的工程规范。这里不记录单轮写作事实，专门放能减少重复事故的编码、脚本、批处理和操作复盘规则。

## 文件说明

- `encoding-and-i18n.md`：UTF-8、中文文本、Markdown/HTML/JSON 编码和乱码排查。
- `lessons/`：操作过程事故复盘。凡是因为流程、脚本或批量操作造成返工的问题，都应新增日期化记录，并同步更新对应规范。

## 自动沉淀规则

当一次操作暴露出可复发的问题时，后续 Agent 应完成三件事：

1. 修复当前文件或流程状态。
2. 在合适位置记录事故、根因、修复动作和防复发规则。
3. 如果事故说明已有规范不足，同步更新本目录或 `docs/agent-rules/` 下的对应规则。

如果只是一次性业务事实，不写入这里，应进入项目 `_ledger/`、`review/`、`docs/reports/` 或作品状态文件。
