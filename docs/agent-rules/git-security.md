# Git 同步与安全规则

## 默认应该同步

- 规则文件、README、项目文档和流程说明。
- 工具源码、schema、模板和测试 fixture。
- Prompt 文件、生成配方、账本、索引、审稿决策、版本流转记录和文本版本清单。
- 小型 SVG、示意图、表格、JSON、Markdown 和可复现脚本。

## 默认不应该同步

- 大型外部资料、缓存、下载目录、临时输出和压缩包。
- 单个项目中尚未筛选的海量候选稿、临时生成结果和无索引输出。
- 包含本机绝对路径、账号信息、token、cookie、私钥或未脱敏外部链接的文件。
- 可以由账本、文本版本清单、prompt 或生成配方重新定位的大体积派生产物。

## 外部资料与临时输出同步

如果需要跨机器恢复大型外部资料或临时输出，应通过网盘、Syncthing、Resilio、rclone 或其他外部同步方式管理；Git 里只保留相对路径、hash、用途和生成记录。

## 安全与隐私

- 不提交密钥、token、cookie、账号凭据和未脱敏内部链接。
- 不把用户本机绝对路径写成长期规则；长期记录优先使用项目相对路径。
- 不默认把外部受版权保护的文本、资料或参考内容复制进仓库；需要引用时记录来源、用途和权限状态。
- 不把未确认可公开的项目设定、商业资料或客户信息同步到公开仓库。
- `.env.example` 只能放占位符和非敏感默认值，真实值只放 `.env`。
