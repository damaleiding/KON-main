# 小说写作规则

## 适用范围

本规则用于章节续写、润色、重写、分支试写、发布整理和写作审稿。它只放跨项目通用约束；具体作品的风格、尺度、禁忌、角色关系和剧情事实，以作品内 `设定/`、`故事圣经.md`、`风格指南.md`、`当前状态.md` 和用户当轮要求为准。

## 生成前必须明确

- 用途：设定整理、章节续写、润色、重写、分支试写、发布整理或临时参考。
- 目标作品、目标章节、输入版本和输出位置。
- 是否允许改动事实、改动视角、扩写剧情、删减段落或只做语言整理。
- 是否需要读取相邻章节、人物卡、伏笔表、风格指南和规避词表。
- 如用户要求规划多章，先按 `plot-and-chapter-planning.md` 确定三章剧情单元、主线/分线和单章目标字数。

## 最小上下文

- 只读目标作品、目标章节和必要索引，不默认读取全部正文。
- 续写必须读最近主干章节、当前状态、故事圣经、伏笔表和出场人物卡。
- 润色必须读目标章节、必要相邻章节、风格指南和出场人物卡。
- 章节重排、合并、拆分必须读章节索引、相邻章节和版本流转记录。

## 正文写作约束

- 不编造未在设定或原文中出现的关键事实；需要新增设定时标记为“待确认”。
- 角色行动必须能从当前状态、关系、欲望、顾虑或外部压力中找到来源。
- 设定不得以说明书方式硬讲；优先通过动作、物件、对白碎片、旁观反应和场景后果带出。
- 叙述视角、人称、时间顺序和信息量必须与目标作品保持一致。
- 对白应服务关系、压力、试探、掩饰或推进，不用对白复述读者已经知道的设定。
- 润色默认保留原章节事实、人物关系和叙事功能，除非任务明确要求重写。

## 章节生成与段落扩写

- 章节生成不是按字数摊长文本；每一段新增内容都必须承担动作、阻碍、反应、选择、信息、关系或后果中的至少一项。
- 扩写短片段前，先标注原段落叙事功能、当前位置、可改事实、不可改事实、目标增量和前后承接点。
- 扩写优先补“缺失过程”：人物如何靠近或避开、拿起或放下、打断或停顿、试探或误解、失败或补救、被环境或他人迫使转向。
- 可以新增子情节，但必须来自既有目标、冲突、物件、时间压力、人物关系或伏笔；不得为凑长度插入与主线无关的插曲。
- 禁止用静态景物、抽象心理、形容词串、名词意象串、同义反复或概念化旁白承担扩写长度。
- 如果需要增加描写，描写必须改变人物行动条件或读者判断，例如遮挡视线、暴露痕迹、延误时间、引发误会或提供选择成本。
- 扩写后检查新增段落是否能被概括成“谁做了什么、遇到什么阻碍、产生什么后果”；不能概括的内容优先删改。

## 更有人写的感觉

- 人写感来自不完全信息下的具体反应，不来自夸饰词密度。
- 人物可以犹豫、误判、改口、停顿、转移话题、先做小动作再说话，但必须符合人物卡和当前压力。
- 情绪不先命名再解释；优先通过选择、回避、手上动作、说漏或没说出口、对方反应和场景后果呈现。
- 保留适度不整齐：句式长短、对白打断、动作和心理交替应随场景压力变化，不把每段都写成对称总结。
- 关键段落应有局部意外，例如小阻碍、小误会、临时决策或物件变化，使正文不是提纲的直接翻译。

## 首尾衔接

- 上一章结尾应留下可承接的动作、物件、声音、未完成状态、问题或人物反应。
- 下一章开头必须接住上一章尾部的空间、时间、情绪或事件后果，不重复上一章已经完成的动作。
- 不在章尾使用总结、宣告、升华或“从此改变”的旁白作为默认收束。
- 如果发生跳时、换地或换视角，章首必须给出清晰但克制的过渡锚点。
- 生成或修改后，应按 `chapter-governance.md` 做相邻章节首尾检查。

## 生成后收口

- 检查设定、角色、伏笔、风格、首尾衔接、规避词和格式。
- 正文内容有修改时，更新章节唯一字数统计，默认口径为非空白 Unicode 字符数。
- 重要生成或改写必须记录 prompt、模型、时间、输入参考、输出路径、版本、用途和筛选结论。
