# 长篇范文学习沉淀

## 总结

本轮范文学习得到的核心结论：长篇连续性不靠“每章都发生很多事”，而靠每一章都继承上一章的状态，并向下一章交付新的状态。状态可以是信息、资源、关系、风险、误判、承诺、物件、位置、身体/心理变化或时间窗口。

## 可落到生成规则的学习点

| 学到的机制 | 生成规则落点 | 具体要求 |
| --- | --- | --- |
| 章节接力 | 章节规划、续写 prompt | 写正文前必须填写“上一章继承状态”和“章尾交付物”。 |
| 可验证事实 | 情节推进、悬疑推进 | 重要信息不能只靠角色口头相信，要有物件、地点、记录、动作或后果来验证。 |
| 状态变化 | 场景规划、段落扩写 | 每个主要场景都要改变人物处境、判断、关系、资源或风险。 |
| 对话功能化 | 对白规划 | 对话必须承担试探、误认、确认、交换信息、威胁、协商、触发行动或改变关系之一。 |
| 成功也有代价 | 章节收束 | 阶段目标完成后，至少留下资源消耗、风险扩大、关系变化或新限制。 |
| 四账本 | 生成后自检 | 每章更新信息账、资源账、关系账、风险账；没有变化则说明该章推进不足。 |
| 双线信息交接 | 多线叙事 | 换视角不等于换线；每次切线要有发送信息、接收信息、验证动作和回传后果。 |
| 问题链 | 悬疑/任务推进 | 疑问 -> 误判/阻碍 -> 验证 -> 代价 -> 新疑问，不能一章抛一个互不继承的谜。 |
| 硬约束连续 | 生存/任务/技术线 | 资源、时间、规则、伤害和环境限制必须被下一章继承，不能危机后复原。 |
| 情绪后果 | 人物线 | 事件结束后人物态度、信任、羞耻、依赖、恐惧或主动性至少改变一项。 |
| 地标/物件锚点 | 场景与伏笔 | 关键地点和物件要能反复承担验证、记忆、危险、承诺或误导功能。 |
| 中段反压 | 三章单元 | 第 2 章应让分线、误判、代价或外部压力反过来干扰主线。 |
| 章尾不升华 | 首尾衔接 | 章尾优先落在未完成动作、物件、声音、现场状态或下一步决定上，不写主题总结。 |
| 失败也推进 | 试错剧情 | 失败必须产生新知识、排除路径或暴露边界，不能只让角色原地受挫。 |

## 章节接力卡

后续正式生成章节前，至少填写：

```text
上一章继承状态：
本章开场压力：
本章核心行动：
本章验证物/关键信息：
人物状态变化：
信息账更新：
资源账更新：
关系账更新：
风险账更新：
章尾交付给下一章的钩子：
禁止断裂点：
```

## 生成后自检

1. 本章是否继承了上一章至少一个具体状态？
2. 本章是否产生了至少一个可继承的新状态？
3. 每个主要场景是否改变了行动、信息、关系、资源或风险？
4. 对话是否推动行动或改变关系？
5. 章尾是否能直接转化为下一章开场动作？
6. 如果本章解决了问题，是否留下新的代价或限制？
7. 如果本章失败，是否产生新知识或排除一条路径？
