# 方法论索引

本目录保存跨项目可复用的小说创作方法论。方法文档应写清楚适用场景、输入、输出、步骤、校验口径和落盘位置；项目专属规则仍放在各项目自己的 `docs/`、`_pipeline/` 或 `WORKFLOW.md`。

## 当前方法

| 文件 | 用途 | 适用场景 |
| --- | --- | --- |
| `longform-reference-analysis-workflow.md` | 长篇范文专项分析工作流 | 分析中长篇小说、系列作品、长篇参考资料，并沉淀为章节地图、篇章地图和可迁移写作技法 |
| `longform-reference-lessons.md` | 长篇范文学习沉淀 | 把范文学到的连续性、账本、问题链和章节接力机制落到后续生成规则 |
