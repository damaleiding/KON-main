# 长篇范文专项分析工作流

## 适用场景

用于把中长篇小说、系列作品或较长参考文本拆成可复用的写作方法。目标不是复述原文，而是学习其章节连续、篇章推进、信息交接、情节升级、资源账本、人物状态变化和结尾钩子。

触发条件：

- 用户要求学习、拆解、吃透、分析某篇长篇或系列作品。
- 参考文本已在项目 `refs/` 下，或用户提供本地 TXT/Markdown/文档。
- 需要把分析成果沉淀为后续写作可复用的规则、检查表或 prompt 参考。

不适用：

- 用户只要单次读后感。
- 用户要求全文复刻、仿写具体桥段或输出受版权保护的大段内容。
- 文本包含敏感或成人向内容时，不能提取露骨桥段，只能抽象结构、节奏和状态变化。

## 标准目录

单文本：

```text
<作品文件夹>/
  README.md
  licensed-texts/
    .gitignore
    README.md
    source-declaration.md
    <原文>.txt
  analysis/
    README.md
    structure-study.md
    chapter-map.md            # 有稳定章标题时
    volume-scene-map.md       # 只有卷标题或篇章标题时
    segment-map.md            # 无稳定标题时
    long-form-techniques.md   # 长篇专项技法总结
```

系列作品：

```text
<作者或系列>/
  README.md
  licensed-texts/
  analysis/
    chapter-by-chapter/
    final-learning-synthesis.md
```

## 输入检查

1. 明确文本来源、作者、作品名、用途和权限状态。
2. 原文只放入 `licensed-texts/`，并确保 `.gitignore` 排除 `*.txt`。
3. 如果用户要求字数统计或正式长度对比，必须调用 `tools/word-count/word-count.ps1` 或 `tools/word-count/word-count.mjs`；结构分析中的字符数只能标为“结构盘点口径”。
4. 判断文本类型：短中篇、长篇、有章标题、只有卷标题、无稳定标题、系列多本文。
5. 判断内容边界：普通文本可做结构分析；敏感/成人向文本只保留非露骨结构抽象。

## 分析步骤

### 1. 结构盘点

生成 `analysis/structure-study.md`，至少记录：

- 文本定位：作者、作品、类型、规模、编码。
- 结构盘点：行数、段落信号、卷标题信号、章标题信号、分隔符信号、对话行占比。
- 使用边界：能学习什么，不能迁移什么。
- 初步观察：这篇文本主要靠什么推进，例如通信、案件、资源、关系、误判、任务或情绪状态。

### 2. 地图选择

根据标题信号选择地图：

- 章标题不少于 8 个：生成 `chapter-map.md`。
- 卷/篇标题不少于 2 个但章标题不足：生成 `volume-scene-map.md`。
- 标题信号不足：生成 `segment-map.md`，按开局、触发、升级、转折、收束分段。

地图只记录结构坐标、规模和功能，不批量摘录原文。

### 3. 长篇专项技法

生成 `analysis/long-form-techniques.md`，把文本的核心长篇方法抽象成：

- 学习定位：这篇最值得迁移的结构能力是什么。
- 核心结构：3 到 6 条可复用机制。
- 上下文连续方法：每章如何承接上一章，如何把结果交给下一章。
- 可迁移章节模板：用表格列出环节、写作问题和输出物。
- KVA 使用规则：后续写作时应该检查哪些账本或状态。
- 学习结论：一句话说明可作为哪类长篇范式。

### 4. 总索引更新

更新所在参考目录的 README 或总索引，记录：

- 作品文件夹。
- 原文组织方式。
- 分析入口。
- 完成状态。
- 可迁移重点。
- 内容使用边界。

## 长篇分析检查表

### 每章连续性

1. 本章继承了上一章的哪个信息、限制或情绪后果？
2. 本章是否产生一个可验证事实、一个可执行行动或一个不可逆关系变化？
3. 结尾是否留下下一章能直接接住的行动、物件、误会、伤害、约定或信息缺口？

### 篇章推进

1. 每一卷或篇章是否有明确阶段目标？
2. 中段是否有主动权变化、信息反转或约束收紧？
3. 阶段成功是否留下新的代价，而不是状态复原？

### 可迁移技法

1. 技法是否抽象到机制层，而不是复述具体情节？
2. 是否能转化为 KVA 的章节规划字段、账本字段或审稿检查项？
3. 是否避开受版权保护的大段表达和敏感桥段？

## Skill 配套

本方法配套本机 Codex skill：`longform-reference-analysis`。

推荐使用方式：

```text
Use $longform-reference-analysis to analyze <path-to-reference-text> into a KVA reference-study folder.
```

该 skill 的脚本负责生成结构盘点和地图骨架；Agent 仍需基于最小必要阅读写出 `long-form-techniques.md`，并更新项目索引。
