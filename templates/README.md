# Templates

本目录保存可复制的新项目模板、prompt 模板、账本模板和交接模板。

## 当前模板

- `project-template/`：小说项目骨架，包含三大入口文件、规则路由、项目级规则目录、账本索引、参考资料、prompt、输出、审稿和废弃材料入口。
- `chapter-plan-template.md`：三章剧情单元规划模板，包含主线、分线、字数目标、章节接力卡、四账本更新和章尾交付物。
- `longform-chapter-generation-prompt-template.md`：长篇章节续写/重写 prompt 模板，内置章节接力卡、旧钩子兑现、四账本/方案账、配角信息动作、问题链和生成后自检。
- `prompt-run-template.md`：Prompt 生成、修改、审稿和版本差异记录模板。
- `story-canvas/`：章节节点、设定增量表和卷/篇章规划模板。
- `story-canvas/draft-node-template.json`：拖出续写草稿、插入章节、分支路线和生成请求字段模板。
- `story-canvas/segment-reroll-template.md`：章内段落级 reroll 记录模板。

## 使用规则

- 新增小说项目时，优先复制 `project-template/`，再替换项目名、作品范围和入口说明。
- 不把具体作品正文或私有设定写入模板。
- 模板只保存可复用结构、字段和规则落点。
