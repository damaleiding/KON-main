# <project-name> 小说创作工作流

## 启动流程

1. 读取 `AGENTS.md`、`PROJECT.md`、`WORKFLOW.md`、`_pipeline/context-routes.md` 和 `_pipeline/rule-router.md`。
2. 明确任务类型：规则修正、设定整理、Prompt 生成/修改、章节续写、章节润色、段落扩写、分支试写、分支合并、发布整理、审稿检查或文本整理。
3. 按 `_pipeline/context-routes.md` 选择最小上下文。
4. 只在任务触发对应流程时读取专项工作流或正文。

## 常见任务

- 设定整理：读取目标作品状态、相关设定和必要章节。
- Prompt 生成/修改：按根 `docs/agent-rules/prompt-generation.md` 生成中文审稿版、模型提交版、版本差异和质量门。
- 故事画布：把每章作为节点管理，记录 reroll、角色变化表、10章篇章和50章卷；画布节点不保存正文全文。
- 三章剧情规划：每章默认 3000 到 6000 字，规划主线动作、分线动作、章内场景、动作链、章首承接和章尾钩子；确认前不写正文。
- 章节续写：读取最近主干章节、故事圣经、当前状态、伏笔表和人物卡。
- 段落扩写：先确认源段落叙事功能、可改范围和动作链缺口，再补阻碍、互动、选择和后果，不靠描写凑长度。
- 章节润色：读取目标章节、必要相邻章节、风格指南和人物卡。
- 首尾衔接检查：读取目标章节和相邻章节，检查尾部与开头是否串联。
- 文风检查：读取风格指南、目标正文和人物卡。
- 规避词表扫描：读取作品词表和目标正文，优先使用确定性搜索。
- 分支合并：先做设定一致性检查，再记录来源和采纳范围。
- 发布整理：只从主干或已确认分支生成。

## 收口要求

- 正文修改后更新唯一字数统计，默认口径为非空白 Unicode 字符数。
- 重要 prompt 按 `prompt-generation.md` 保存到 `prompts/` 或输出旁 `_prompts/`。
- 重要改写、合并、发布和审稿结论写入 `_ledger/` 或 `review/`。
