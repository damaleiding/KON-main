# 文风质量规则模板

## 检查维度

- 叙述声音：
- 章节节奏：
- 角色对白：
- 设定呈现：
- 修辞密度：
- 词汇边界：
- 事件含量：
- 动作链与后果：
- 反灌水约束：

## 人写感检查

- 新增段落是否有动作、阻碍、互动、选择、信息或后果。
- 删除形容词、名词意象和抽象心理词后，段落是否仍然成立。
- 对白是否服务试探、回避、压迫、交易、误解、拒绝、让步或遮掩。
- 人物是否在具体压力下做出有成本、会留下后果的反应。

## 作品级依据

- `设定/风格指南.md`
- `设定/故事圣经.md`
- `设定/当前状态.md`
- `设定/人物卡/`

## 沉淀规则

单次问题先进 `review/` 或 `_ledger/`；反复出现并经确认的问题，再沉淀为作品级风格规则或规避词表。
