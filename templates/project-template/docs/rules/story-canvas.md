# 故事画布规则模板

## 默认结构

- 每章一个章节节点。
- 每 10 章为一个大篇章。
- 每 5 个大篇章为一卷，即 50 章。
- 一卷内核心故事方向锁定；改变前需要用户确认。

## 节点字段

| 字段 | 说明 |
| --- | --- |
| 节点 ID | 稳定唯一标识 |
| 所属卷 | 例如 `v01` |
| 所属篇章 | 例如 `v01-a01` |
| 章节号 | 全局章节号 |
| 目标字数 | 默认 3000-6000 |
| 主线动作 | 本章推进主线的具体动作 |
| 分线动作 | 本章推进关系、秘密、伏笔或场景线的动作 |
| reroll 记录 | 候选版本、状态和结论 |
| 剧情段 reroll | 章内段落级候选版本和替换状态 |
| 角色变化表 | 本章角色增量 |

## 剧情段 reroll

- 章内任意段落可以作为剧情段独立 reroll。
- 剧情段必须保存选区锚点，例如段落号、起止字符位置、原文短引或前后文短引。
- 剧情段候选只替换该段，不覆盖整章。

## 角色变化表

| 角色 | 本章新行为 | 状态变化 | 关系变化 | 新秘密/信息 | 人物卡同步 | 来源版本 |
| --- | --- | --- | --- | --- | --- | --- |

人物卡同步状态：`pending`、`synced`、`branch-only`、`rejected`。
