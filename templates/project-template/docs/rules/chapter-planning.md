# 三章剧情单元规则模板

## 默认值

- 单章目标长度：3000 到 6000 字。
- 默认统计口径：非空白 Unicode 字符数。
- 默认规划单位：三章为一个剧情单元。

## 三章职责

- 第 1 章：承接上一章尾部，建立单元问题和主线钩子。
- 第 2 章：加压、误导、转折，或让分线干扰主线。
- 第 3 章：阶段性回收本单元问题，并留下下一单元钩子。

## 单章字段

```text
章节编号：
目标字数：
章节功能：
主线动作：
分线动作：
章内场景：
动作链：
段落扩写点：
子情节来源：
章首承接：
章尾钩子：
反灌水要求：
待同步：
```

## 段落扩写原则

- 扩写前先确认原段落功能、前后承接、可改范围和不可改事实。
- 扩写靠补动作链、阻碍、互动、选择、误解、物件变化、信息变化和小后果完成。
- 不用静态景物、抽象心理、形容词串、名词意象串或同义反复凑长度。
