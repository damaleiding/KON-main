Pixiv Novel 小说创作项目纲要

项目目标

本目录是 KVA 的整体小说创作项目，用于统一管理多部小说作品、通用写作经验、设定资料、正文版本、分支稿、发布稿、提示词、审稿记录和工具流程。

核心文本

  • 曲影番外二/：当前重点生产作品，已有设定、人物卡、拆章主干、局部账本和 Google Docs 同步稿，优先沉淀可复用流程。
  • 人偶番外/：已有原文、设定、主干章节、重设分支、增补分支和发布稿。
  • 柠檬/：已有原文、设定资料、拆章主干和新作分支。
  • 曲影/：已有原文、人物卡、设定资料和润色主干，可作为曲影系列基础设定来源。

阅读入口

  • AGENTS.md：项目级规则，强调最小上下文、触发式工作流和经验复用。
  • PROJECT.md：项目记忆和当前状态。
  • WORKFLOW.md：项目整理、写作、润色、合并、发布和方法沉淀流程。
  • _pipeline/context-routes.md：不同任务的最小上下文读取路线。
  • docs/current-layout.md：当前目录映射和整理建议。
  • _ledger/：写作记录、审稿决策和版本流转记录；默认不整目录读取。

当前状态

项目入口和骨架目录已建立，规则已收敛为轻量路由。既有正文暂时保留原路径，避免破坏已有 skill、脚本、Google Docs 同步稿或人工路径习惯。

下一步建议

  • 从 曲影番外二/ 沉淀项目级写作流程、审稿规则、提示词和同步方法。
  • 为每个作品补齐作品索引和当前状态表。
  • 把可复用 prompt 整理到 prompts/。
  • 移动正文文件前先生成迁移表并确认引用风险和回滚方式。
