# Novel 工作流

## 启动流程

1. 读取 `AGENTS.md`、`PROJECT.md` 和本文件。
2. 读取 `_pipeline/context-routes.md`，按任务选择最小上下文。
3. 如果任务指向具体作品，先读该作品 `设定/`，再读 `主干/` 或指定 `分支/`。
4. 如果任务涉及正文、剧情、对白、润色、改写或发布，按 `_pipeline/character-card-workflow.md` 读取出场人物的人物卡。
5. 如果任务会修改既有正文，先按 `_pipeline/text-version-backup-workflow.md` 备份本次会改动的文件。
6. 如果任务涉及合并、发布或大幅重写，先查 `_ledger/` 和作品内状态记录。
7. 如果任务涉及生成后复查或用户指定检查章节，按 `_pipeline/chapter-self-check-workflow.md` 执行自检。
8. 如果任务涉及 Google Docs、`clasp` 或 Apps Script 同步，按 `_pipeline/google-docs-clasp-sync-workflow.md` 执行。

## 常见任务

- 设定整理：读取作品 `设定/`，输出到同目录或 `docs/`，新增事实标记为待确认。
- 章节润色：读取目标章节、风格指南、必要设定和出场人物卡，输出到原路径前先确认是否覆盖；默认输出到 `outputs/` 或指定分支。
- 分支试写：在 `分支/<方向名>/` 下写作，不直接覆盖 `主干/`；分支人物经历应标注来源和采纳状态。
- 分支合并：先做设定一致性检查，再记录来源章节、采纳范围和替代内容。
- 发布整理：只从 `主干/` 或已确认合并的分支生成，输出到 `发布/`。
- 人物卡同步：每个主要角色维护独立人物卡；正文新增或改动角色经历、关系、心理、状态、秘密或伏笔时，同步更新或在最终回复中列出待确认条目。
- 正文备份：覆盖、拆分、合并、格式清理、编码修复、字数统计更新前，必须先把本次会改动的章节复制到 `_backups/text-history/`。
- 章节自检：读取目标章节、`故事圣经.md`、`风格指南.md`、`当前状态.md`、`伏笔表.md`、`分支记录.md`、`角色卡.md` 和出场角色人物卡，只输出设定、角色、风格、伏笔、格式、待同步项和修改建议，不直接改正文。
- 正文修改：只有用户明确要求修改时执行；先备份目标文件，再按用户确认的建议修改，修改后复查，并写入对应分章节账本，同时更新 `_ledger/iteration-ledger.md` 总索引；若目标版本已绑定 Google Docs，默认继续执行覆盖同步。
- Google Docs 同步：先确认来源版本、目标文档、新建/覆盖/追加策略和本机 `clasp` 环境；同步后记录结果，后续正文改动默认继续同步到同一目标文档；上传稿应尽量保留本地 Markdown 的标题、分隔线、段落和字数统计，并采用更松的断句分段方便审阅。

## 记录要求

- 章节字数统计：每一部分/每一章正文（含分支和润色稿）的结尾处必须且只能带有一行字数统计。如果原文件已有字数统计，在修改正文后必须先删除旧统计，再同步更新为唯一的新统计。统计口径为“非空白字符”。格式示例：`> 本章字数统计：XXXX 字（非空白字符）`
- 重要 prompt 保存到 `prompts/`，或保存到输出旁的 `_prompts/`。
- 大段改写记录任务目标、输入文件、输出文件、模型、版本差异和审稿结论。
- 分支合并记录来源、目标、合并范围、删除或替代内容。
- 发布稿记录来源章节、排版规则、上传目标和最终文件路径。
- Google Docs 同步记录来源路径、Google 文档标题或脱敏 ID、同步模式、排版策略、`clasp`/Drive 执行结果和待处理失败项。
- 人物卡更新记录来源章节、分支名、状态、改动内容和是否进入主干。
- 自检记录至少说明检查对象、读取依据、结论、发现问题、修改建议、待同步设定/人物卡/伏笔条目；没有问题也要说明未发现冲突和未覆盖范围。
- 迭代账本：每次用户要求修改后，为目标章节创建或更新分章节账本，路径为 `_ledger/iterations/<作品名>/<版本或分支名>/YYYYMMDD_<作品名>_<版本或分支名>_<章节编号或章节名>_<操作类型>.md`；总索引 `_ledger/iteration-ledger.md` 只登记账本路径、操作日期、作品、版本、章节和一句话结论。

## 文件移动原则

- 不直接移动既有正文、设定和发布稿。
- 需要重排目录时，先生成迁移表，包含旧路径、目标路径、用途、是否被 skill 引用、迁移风险。
- 迁移完成后，同步更新 `README.md`、`PROJECT.md`、`_pipeline/context-routes.md` 和相关作品索引。
