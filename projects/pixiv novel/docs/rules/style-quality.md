# 文风质量规则

## 项目级检查维度

- 叙述声音：人称、距离、旁白密度和信息披露方式。
- 节奏结构：动作、心理、对白、环境描写比例。
- 角色声音：对白是否符合人物卡和当下关系。
- 设定呈现：是否通过动作、物件、对话和后果呈现，而不是直接说明。
- 修辞习惯：是否出现过度比喻、排比、口号化总结或抽象升华。
- 词汇边界：是否命中作品级禁用词、慎用词或不合时代/身份的表达。

## 检查流程

1. 读取 `_pipeline/style-quality-check-workflow.md`。
2. 读取目标作品 `设定/风格指南.md`。
3. 读取目标正文和出场人物卡。
4. 如果涉及禁用词，读取 `_pipeline/avoidance-lexicon-workflow.md`。
5. 输出问题、依据、建议和待同步项。

## 沉淀方式

- 单次问题先进入 `review/` 或 `_ledger/`。
- 反复出现并经用户确认的表达问题，再沉淀到作品级规避词表。
- 不把具体作品文风硬套给其他作品。
