# 三章剧情单元与章节长度规则

## 项目默认值

- 单章目标长度：3000 到 6000 字。
- 默认统计口径：非空白 Unicode 字符数。
- 默认规划单位：三章为一个剧情单元。

## 三章单元职责

- 第 1 章：建立单元问题、承接上一章尾部、给出主线钩子。
- 第 2 章：加压、误导、转折或让分线主动干扰主线。
- 第 3 章：阶段性回收本单元问题，同时留下下一单元钩子。

## 主线与分线要求

- 每章必须有主线动作，不能只有氛围或解释。
- 三章内至少一条分线要持续变化，例如角色关系、秘密、伏笔、任务、场景规则或对照人物。
- 分线不能和主线平行空转；最好在第 2 章或第 3 章反过来推动主线。
- 伏笔表需要记录新埋、强化、误导、回收或暂缓的状态。

## 章节接力卡

正式续写或重写单章前，先按 `longform-generation.md` 填写章节接力卡。三章规划表中至少要能回答：

- 上一章继承状态：上一章留下的信息、限制、情绪后果、资源变化、物件、承诺或风险窗口。
- 本章开场压力：本章前 10% 篇幅内要出现的具体压力。
- 本章核心行动：角色主动做什么，不能只有解释或氛围。
- 本章验证物/关键信息：用什么物件、地点、记录、行动或对话改变判断。
- 四账本更新：信息账、资源账、关系账、风险账至少一项变化。
- 章尾交付物：下一章必须接住的动作、决定、误会、伤害、约定、风险或信息缺口。

没有接力卡的规划只能视为草案，不进入正式生成。

## 规划落点

- 临时规划：聊天或 `outputs/`。
- 已确认规划：作品 `设定/章节规划.md` 或 `_ledger/`。
- 长期规则：本文件和根 `docs/agent-rules/plot-and-chapter-planning.md`。
- 不写入项目三大入口文件全文。

## 检查问题

- 这一章为什么不能删除？
- 这一章主线推进了什么？
- 这一章分线变化了什么？
- 这一章继承了上一章什么具体状态？
- 这一章更新了信息、资源、关系或风险中的哪一账？
- 章尾给下一章留下了什么具体可写点？
- 字数是否落在 3000 到 6000 字范围内？
