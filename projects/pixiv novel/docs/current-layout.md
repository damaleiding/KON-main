## 结构调整注意事项

- 移动正文前必须先确认是否被 skill、脚本、发布流程、Google Docs 同步稿或人工习惯引用。
- 迁移不应覆盖 `原文/`；需要修改时先生成工作稿。
- 每次结构调整后同步更新 `README.md`、`PROJECT.md`、`WORKFLOW.md`、`_pipeline/context-routes.md` 和相关作品索引。
- `_backups/`、`review/` 和 `_ledger/` 不直接删除；整理时应按作品或方法分类保留引用记录。
