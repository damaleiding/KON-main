# 范文参考索引

本目录保存用于写作研究的范文资料入口。既有 Pixiv 单篇参考，也有中长篇小说研究资料；默认不整目录读入上下文，只按任务读取对应作品文件夹内的分析文件。

## 当前规则

- 一个文本一个文件夹；系列作品可合并为一个系列文件夹。
- 原文 TXT 统一放入对应文件夹的 `licensed-texts/`，并由该目录内 `.gitignore` 排除。
- 分析成果统一放入 `analysis/`，优先读取分析文件，不直接读取全文。
- 敏感或成人向文本只学习结构、节奏、视角、状态变化和上下文衔接，不迁移具体桥段。
- 中长篇优先补充章节/篇章地图和可迁移技法总结。
- 后续新增长篇范文，优先按工作区 `methods/longform-reference-analysis-workflow.md` 执行；可调用本机 Codex skill `longform-reference-analysis` 生成结构脚手架。

## 分析文件口径

| 文件 | 用途 |
| --- | --- |
| `analysis/structure-study.md` | 单篇首轮结构学习：规模、标题信号、对话密度、情节安排、上下文衔接和 KVA 可迁移规则 |
| `analysis/segment-map.md` | 无稳定章标题文本的分段地图，按开局、触发、升级、转折、收束记录 |
| `analysis/chapter-map.md` | 有稳定章标题长篇的章节地图，只记录序号、行号、规模和结构功能 |
| `analysis/volume-scene-map.md` | 只有卷标题的长篇地图，按卷和卷内结构块学习 |
| `analysis/long-form-techniques.md` | 长篇专项技法总结，可直接迁移到 KVA 章节规划 |
