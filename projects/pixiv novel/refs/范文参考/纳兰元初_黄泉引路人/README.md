# 纳兰元初《黄泉引路人》参考研究

## 用途

本目录用于把纳兰元初《黄泉引路人》系列作为中长篇范文研究对象，重点观察：

- 中长篇情节如何从日常场景进入异常事件。
- 章节之间如何承接线索、危险、人物状态和悬念。
- 单部作品如何用封闭场景承载多线调查。
- 系列续作如何继承上一部事件后果，同时换场景、换问题、扩大世界观。

## 版权与收录状态

本目录不保存未经授权的全文。

当前已查到《断龙台》和《邪兵谱》存在微信读书、豆瓣等公开书目信息与正规阅读入口；搜索中也出现了若干全文转载站，但未确认授权，不纳入仓库，不作为默认参考源。

用户已提供本地 TXT，并已放入 `licensed-texts/` 子目录；该目录已用 `.gitignore` 排除 `*.txt`，全文默认不进入 Git。

## 本目录文件

- `source-notes.md`：资料来源、正版入口、版权处理和书名核验。
- `continuity-study-plan.md`：后续拿到合法全文后，用于拆解上下文连续、章节钩子和情节安排的研究模板。
- `public-info-observations.md`：基于公开简介和书评的初步结构观察，所有结论都标记为待全文核验。
- `licensed-texts/source-declaration.md`：用户提供 TXT 的编码、导入和 Git 边界说明。
- `analysis/`：全文级结构拆解输出。
