# 黄泉引路人学习派生 Prompt

这些 prompt 用于把《断龙台》《邪兵谱》的学习结果应用到 KVA 项目，不要求模仿原文，只迁移结构技法。

## 三章规划 Prompt

```text
请为目标作品规划一个三章单元，重点学习《断龙台》《邪兵谱》的连续推进方式，但不要模仿具体文本。

必须输出：
1. 三章各自的日常场景。
2. 每章的现实任务或现实压力。
3. 一个贯穿三章的主物件：第一章出现，第二章误用/转交/丢失，第三章暴露真实功能。
4. 每章章尾的具体未解决状态。
5. 下一章必须处理的物件、伤口、证据、地点或情绪。
6. 群像角色的信息分工：谁看见、谁误会、谁保存证据、谁阻挠、谁行动。
7. 静默期是否存在；如果存在，说明暗中推进了什么。

禁止：
- 用抽象主题收尾。
- 让专家角色一上来长篇解释。
- 让现实任务在异常发生后消失。
```

## 章节续写 Prompt

```text
请续写目标章节，重点保证上下文连续。

续写前先检查：
- 上一章留下的具体物件/状态是什么？
- 当前角色的现实任务是什么？
- 哪个配角可以承担信息功能？
- 专家角色是否需要先行动再解释？

续写要求：
1. 章首先处理上一章留下的具体后果，不复述上一章剧情。
2. 新异常必须绑定角色正在处理的动作或现实任务。
3. 至少让一个物件进入下一章。
4. 章尾留下具体未完成状态：动作、地点、物件、证据、伤口或关系变化。
5. 不写总结式升华，不写“从此改变”。
```

## 章节自检 Prompt

```text
请检查目标章节的连续性，按以下表格输出：

| 项目 | 判断 | 问题 | 修改建议 |
| --- | --- | --- | --- |
| 章首是否承接上一章具体后果 |  |  |  |
| 本章是否保留现实任务 |  |  |  |
| 本章是否有主物件或证据链 |  |  |  |
| 配角是否承担信息功能 |  |  |  |
| 专家/掌控者是否先行动再解释 |  |  |  |
| 静默期是否推进了关系或线索 |  |  |  |
| 章尾是否具体而非总结 |  |  |  |
| 下一章必须处理什么 |  |  |  |

只给结构和修改建议，不复制大段原文。
```

## 尾声整理 Prompt

```text
请为一个篇章设计尾声，学习《断龙台》的后果清算方式。

尾声必须处理：
1. 谁留下收拾残局。
2. 谁离开或失去联系。
3. 哪个场景被重建、废弃或改名。
4. 哪个配角被重新理解。
5. 哪个物件被保留、交还、销毁或成为下一部影子。
6. 主角的现实生活如何继续。

禁止：
- 抽象总结主题。
- 用旁白宣布人物成长。
- 忽略配角和场景后果。
```
