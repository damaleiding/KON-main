## 学习结论

- 全书不是单一悬念线，而是“空间异常 -> 刑案 -> 公司人事 -> 术法物件 -> 历史冤案”的连续加深。
- 每次扩大问题之前，都先用具体行动承接：取珠、坐电梯、开会、封楼、夜查、设酒会、查档案。
- 尾声很重要：它让前文配角和场景都有后果，不让终局停在打斗胜负。
