# 《断龙台》尾声二学习

## 本单元功能

尾声二把顾青从公司后果带到宋巧稚养父母家，处理亲缘余波，并放入续作影子。

## 场景拆解

| 内容 | 结构作用 |
| --- | --- |
| 顾青想探望宋巧稚养父养母 | 主动处理姐姐线后果 |
| 老人讲宋巧稚曾安排好他们生活 | 让宋巧稚不只停留在怨魂形象 |
| 门铃响起，一个与刘天明相似的人出现 | 系列人物回声出现 |
| 刘天影登场 | 为《邪兵谱》或后续系列埋影子 |
| 全书完结提示续作 | 系列结构收束又打开 |

## 承接尾声一

尾声一处理公司、建筑和钱款；尾声二处理亲缘、记忆和系列未来。两个尾声分工清楚，一个现实清算，一个情感回声。

## 技法提炼

- 第二尾声适合处理主线之外但情感上必须被看见的人。
- 死者的善意安排能让人物从“受害者/怨魂”恢复为完整的人。
- 续作影子最好以人物出现，而不是广告式解释。

## 对 KVA 的写作提醒

- 结尾不要只处理主角，要处理被事件伤害和牵连的人。
- 系列钩子要轻，像一次偶遇或一个名字回声。
- 双尾声结构很实用：一篇清算，一篇余韵。
