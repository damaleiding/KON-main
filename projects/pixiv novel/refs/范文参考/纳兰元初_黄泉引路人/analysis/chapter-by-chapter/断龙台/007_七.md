# 《断龙台》七学习

## 本单元功能

这一节把顾青从与宇文的临时安全感中拉出来，推入梦魇和警方问询。

它完成四个推进：

1. 用绿色天空梦境说明异常已经进入顾青内心。
2. 让刘天明正式把顾青带入案件调查。
3. 通过监控、保安状态和“蓝月”信息，把宇文重新放上嫌疑台。
4. 让顾青在信任宇文和配合警方之间发生动摇。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 顾青梦见异常天空、公交车和怪异人群 | 大厦异常突破物理空间，进入梦境 |
| 2 | 她惊醒后试图用日有所思解释梦 | 人物先用常理自我安抚 |
| 3 | 刘天明来电，要求她去警局配合 | 私人梦魇被现实案件打断 |
| 4 | 张建国接她去公安局 | 小张作为警方支线人物登场 |
| 5 | 刘天明以较正式的状态接待顾青 | 现实调查线变得严肃 |
| 6 | 刘天明讲述幸存保安、蓝月和现场信息 | 私人遭遇被刑侦材料化 |
| 7 | 监控录像和宇文行为被提出 | 宇文从救援者再次变成疑点人物 |
| 8 | 刘天明追问宇文特殊之处 | 顾青被迫重新评估宇文 |
| 9 | 顾青提到玄罡 | 以轻微错位的回答收尾，既缓解又继续埋线 |

## 承接上一节

上一节通过热红薯和宇文照顾，建立了顾青对宇文的信任。本节立刻把这个信任放进审问环境里测试。

这是一种很有效的承接：上一章让人物关系升温，下一章就让外部系统质疑这段关系。

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 顾青开始被梦魇侵蚀 | 绿色天空和公交梦境 | 异常不再只靠现场触发 |
| 幸存保安精神失常 | 刘天明的案件信息 | 凶案后果继续扩大 |
| “蓝月”成为关键词 | 保安反复念叨 | 把不可解释内容压缩成可追踪词 |
| 宇文有伪造或遮掩行为 | 警方从监控角度提出疑点 | 专家角色也要接受现实逻辑审视 |
| 顾青开始矛盾 | 她既记得宇文保护，也承认他可疑 | 主角信任不能无成本 |

## 章尾钩子

章尾是顾青在高压追问下，说出宇文养着一条大狗。

它有两个效果：

- 以轻微滑稽降低审问压迫。
- 把玄罡从第六节的温暖/解释功能，带入警方视野。

## 技法提炼

### 技法 1：关系升温后立刻测试

第六节让宇文可靠，第七节让警方指出他可疑。人物关系因此立体。

可迁移到 KVA：不要让信任单向增加；每一次靠近后，都安排一个外部质疑。

### 技法 2：把恐怖词汇证据化

“蓝月”不是完整解释，而是一个可重复、可追查的关键词。

可迁移到 KVA：神秘信息最好先以短词、符号、数字、图案出现。

### 技法 3：梦境要和现实案件互相映照

顾青的梦不是单纯氛围，而是和她被卷入调查的心理状态同步。

可迁移到 KVA：梦境之后要马上有现实动作承接，否则容易散。

## 对 KVA 的写作提醒

- 梦境段要服务人物状态和线索关键词。
- 现实调查者应从证据角度挑战主角的情感判断。
- 新关键词出现后，要进入后续索引，不能只做气氛。
- 审问场景可以用一个错位回答缓冲沉重感。

## 下一单元学习重点

下一节“八”要观察：宇文被警方正面审视时如何应对；刘天明如何判断他既可疑又不完全像凶手。
