# 《断龙台》十五学习

## 本单元功能

这一节把顾青从受害者推向协助者，同时补足宇文的生活面和术法面。

它完成四个推进：

1. 以阁楼清晨和尴尬日常展示宇文不神秘的一面。
2. 让顾青看到虚灵金枪和宇文练习，确认他也在临阵准备。
3. 讨论浑沌、梦魇和珠串，回收开局书架线。
4. 顾青因自责和责任感要求同行，形成新的主角行动关系。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 宇文在阁楼醒来，玄罡也疲惫 | 专家生活状态落地 |
| 2 | 宇文练习虚灵金枪，被顾青意外撞见 | 能力展示与生活尴尬结合 |
| 3 | 两人围绕术法和兽灵谱交流 | 顾青开始参与分析，而非只听解释 |
| 4 | 宇文判断顾青梦境被游魂干扰 | 梦魇线被纳入术法解释 |
| 5 | 开局珠串和浑沌关系被进一步讨论 | 书架物件线回收 |
| 6 | 顾青意识到自己可能引发或放出了问题 | 主角自责出现 |
| 7 | 宇文安慰她，说明怪物迟早会害人 | 减轻负罪，同时保留责任 |
| 8 | 顾青坚定要求一起行动 | 主角从被保护对象转为主动参与者 |
| 9 | 宇文用玩笑和玄罡缓冲沉重情绪 | 以日常喜剧收束，关系继续升温 |

## 承接上一节

上一节顾青连续梦魇，宇文暂住阁楼。本节立刻从阁楼清晨开始，兑现住宿安排，也把梦魇带入讨论。

同时，本节回收最早的书架珠串，使开局物件没有被战斗线吞没。

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 宇文也要练习和准备 | 虚灵金枪训练 | 专家不是随时满状态 |
| 顾青能做资料分析 | 她查兽灵谱并推断浑沌 | 主角能力从职场理性转为调查助力 |
| 梦魇可能是游魂干涉 | 宇文解释梦的机制 | 梦境线进入规则系统 |
| 开局珠串与大厦危险相关 | 讨论中回收物件线 | 早期物件要中段再发挥 |
| 顾青决定参与 | 她要求同行 | 人物身份发生阶段性转变 |

## 章尾钩子

章尾是顾青要求加入行动，而宇文没有直接把她推开，只用玩笑缓冲。

下一阶段的问题变成：顾青能怎样帮忙？她参与后会带来线索，还是增加风险？

## 技法提炼

- 专家生活面和能力面放在同一场，会更有人味。
- 主角从受害者到协助者，要经历自责、判断和主动请求。
- 早期物件线中段必须回收，否则开局钩子会失效。
- 沉重责任感后用轻松动作收尾，可以保护阅读节奏。

## 对 KVA 的写作提醒

- 主角加入行动不能只靠勇敢宣言，要有她能提供的能力。
- 专家准备不足、临阵练习，会让危机更真实。
- 每十章左右要回收一次早期关键物件。
- 关系升温最好通过共同分析和共同承担实现。

## 下一单元学习重点

下一节“十六”要观察：宇文如何把大厦解释成阵法/空间系统；顾青如何从协助意愿进入夜入大厦的实际准备。
