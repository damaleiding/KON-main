# 《断龙台》四学习

## 本单元功能

这一节把顾青的个人惊吓推入现实系统：大厦封锁、保安惨案、警方调查和公司危机同时出现。

它完成四个推进：

1. 用第二天上午的封锁现场，证明昨夜不是顾青的幻觉。
2. 让陈词透露一死一疯，把个人恐怖升级为刑事案件。
3. 让刘天明登场，把警方线正式接入主线。
4. 让顾青在危机中恢复行政主管身份，主动组织酒店会议。

这一节的关键，是让“异常事件”不再只发生在夜晚和电梯里，而是污染白天的公司秩序。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 顾青第二天到大厦，发现入口被警戒带和警察封住 | 用公共封锁确认事件真实存在 |
| 2 | 同事聚集，陈词接受询问并试图隐瞒 | 公司秩序崩坏，管理层压力出现 |
| 3 | 顾青识破“炸弹”说法，逼问陈词 | 展示顾青的职业敏锐和压迫力 |
| 4 | 陈词透露保安一死一疯，地点与顾青办公室楼层相关 | 将顾青昨夜经历与现实惨案连接 |
| 5 | 刘天明乘警车出现 | 刑侦线入场，案件获得现实调查者 |
| 6 | 顾青与刘天明初次互相观察 | 两个强势现实人物建立关系张力 |
| 7 | 刘天明纠正现场疏散问题 | 用行动证明他并非摆设，具有现场判断力 |
| 8 | 顾青打听宇文情况，确认他被警方带走 | 专家线被现实系统捕获，下一步会受审视 |
| 9 | 顾青拒绝回家休息，转而要求租酒店会议室开会 | 主角从惊吓状态切回工作状态，推动公司线 |

## 承接上一节

上一节宇文拿着珠串返回大厦，留下“楼里会发生什么”的问题。第四节用第二天封锁直接回答：大厦确实出事了，而且后果已经进入公共视野。

这种承接不是让顾青当场看到宇文行动，而是通过结果反推昨夜危险的严重性。读者会自然追问：宇文回去后是否来得及？珠串和惨案有什么关系？

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 大厦发生重大案件 | 警戒带、警察、同事聚集 | 异常后果进入白天和公共秩序 |
| 陈词不可靠但有信息 | 他试图隐瞒，又在顾青逼问下透露 | 配角可以同时承担阻碍和信息源 |
| 保安惨案与顾青昨夜相关 | 顾青回想昨晚见过的保安 | 让主角意识到自己与案件只差一步 |
| 刘天明是现实调查线核心 | 自我介绍、现场处置、警务判断 | 现实系统不是背景，而是主线压力源 |
| 宇文被带走 | 陈词提供消息 | 专家角色开始被现实规则审查 |
| 顾青仍有职场任务 | 她安排酒店会议 | 恐怖事件不暂停现实责任 |

## 章尾钩子

章尾是顾青把大厦无法进入的困境转化为酒店会议。

这个钩子不是恐怖画面，而是行动方向：

- 公司内部矛盾即将展开。
- 顾青会在现实权力结构里碰到新阻力。
- 大厦封锁期间，故事可以切到公司管理线，而不是停滞等待警方。

这使小说开始形成双线：异常案件线和公司权力线。

## 技法提炼

### 技法 1：用公共后果证明私人恐惧

顾青昨夜的经历很像幻觉，第二天封锁现场把它钉回现实。

可迁移到 KVA：

- 主角单独遭遇异常后，下一章最好出现一个公共后果。
- 公共后果可以是警戒线、公告、人员缺席、设备封存、会议取消。

### 技法 2：配角隐瞒也是信息释放

陈词试图遮掩，但顾青通过他的漏洞获得更真实的信息。隐瞒本身制造压力。

可迁移到 KVA：

- 不要让配角直接汇报真相。
- 让主角通过追问、识破和对方失态获取信息。

### 技法 3：现实调查者要有独立锋芒

刘天明登场不是来听主角讲故事，他有自己的判断、脾气和现场处置方式。

可迁移到 KVA：

- 警方、医生、公司管理层等现实人物不能只是工具人。
- 他们要用专业动作改变现场。

### 技法 4：危机中继续工作线

大厦封锁后，顾青没有被动等待，而是把会议地点转移到酒店。这让她的主角能力落在现实行动上。

可迁移到 KVA：

- 现实任务不要被异常事件完全吞掉。
- 主角处理现实任务时，可以暴露新的敌对关系。

## 对 KVA 的写作提醒

- 私人遭遇之后，下一章要给一个白天的公共后果。
- 引入警方线时，先让警方改变现场，而不是只听讲述。
- 公司线、职场线、家庭线都可以成为悬疑的现实容器。
- 章尾不一定要吓人，也可以是新的行动场景被明确安排。

## 下一单元学习重点

下一节“五”要观察：酒店会议如何引出杜听涛和公司内部权力；顾青如何在工作受挫后再次被大厦异常拉回。
