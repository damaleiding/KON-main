# 规避词表工作流

## 触发场景

- 用户要求建立、补充、检查或扫描规避词表。
- 文风审稿发现反复出现的不合适词汇、句式、比喻或语气。
- 发布前需要检查禁用词、慎用词或替代表达。

## 词表位置

- 项目级说明：`docs/rules/avoidance-lexicon.md`。
- 作品级词表：优先放在目标作品 `设定/风格指南.md` 或 `设定/规避词表.md`。
- 临时审稿命中：先写入 `review/` 或 `_ledger/`，确认后再沉淀为作品级词表。

## 字段

| 字段 | 说明 |
| --- | --- |
| `term` | 词语、短语、句式或比喻 |
| `category` | banned / caution / replace / allowed |
| `scope` | 全作品、角色、视角、版本、发布稿 |
| `reason` | 原因 |
| `suggestion` | 替代表达或处理方式 |
| `source` | 用户要求、审稿结论、风格指南、历史问题 |
| `updated` | 日期 |

## 扫描方法

1. 读取目标词表和目标文本。
2. 对精确词条优先使用 `rg -n -F "<term>" <path>`。
3. 对句式或语气问题，使用人工审稿判断并给出依据。
4. 输出命中位置、短引、风险级别和处理建议。
5. 批量替换前必须执行正文备份工作流。

## 禁止事项

- 不把一次临时偏好直接升级为全项目硬规则。
- 不机械替换角色台词、专名、引用旧文或有意保留的风格痕迹。
- 不把完整规避词表复制进 `AGENTS.md`、`PROJECT.md` 或 `WORKFLOW.md`。
