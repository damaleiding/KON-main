# Novel Ledger

`_ledger/` 用于记录小说创作工程中的重要生产事实，避免只依赖聊天历史。

## 建议记录内容

- 章节续写：输入章节、参考设定、输出路径、模型、prompt 文件、版本差异。
- 润色改写：原文路径、改写目标、输出路径、采用状态、被替代内容。
- 分支合并：来源分支、目标主干、合并范围、冲突点、审稿结论。
- 发布整理：来源章节、发布稿路径、排版规则、上传目标、最终状态。
- 设定变更：变更文件、变更原因、影响角色或章节、待确认问题。
- 项目迭代：按章节记录用户要求、检查建议、采纳方向、实际改动、复查结论和故事理解沉淀。

## 推荐文件

- `writing-log.jsonl`：写作和改写流水。
- `review-decisions.jsonl`：审稿、采纳、拒绝和返工决策。
- `prompt-index.md`：重要 prompt 的入口索引。
- `migration-log.md`：目录整理和文件迁移记录。
- `iteration-ledger.md`：项目迭代总索引，只登记分章节账本路径、网页报告路径和一句话结论。
- `iterations/<作品名>/<版本或分支名>/YYYYMMDD_<作品名>_<版本或分支名>_<章节编号或章节名>_<操作类型>.md`：分章节迭代账本，记录每次检查、修改和长期故事方向沉淀。
- `review/YYYYMMDD_<作品名>_<版本或分支名>_<章节编号或范围>_自检建议.html`：自检建议网页报告，用于持续查看问题、证据引用和任务状态；每个问题应是可双击展开的模块，详情区用原文短引、注释、标红和背景色辅助理解；用户确认已修复后，在页面中以删除线保留问题。
