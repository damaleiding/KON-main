# Story Engine 参考资料索引

本目录保存 Story Engine 的跨作品参考资料、范文学习、结构分析和可迁移技法。

参考索引和 analysis 已迁入本项目；迁移时未批量复制 `licensed-texts/` 原文目录，后续需要按授权、忽略规则和体积逐项处理。

## 子目录

- `范文参考/`：可用于文风、结构、章节衔接、情节安排和叙事技法研究的范文入口。

## 使用原则

- 未确认授权的全文不进入仓库。
- 参考资料必须标注作品、作者、来源、用途、状态和注意事项。
- 废弃、风险不明或未经筛选的参考不得默认进入 prompt。
- 真正要用于写作前，应先整理为技法、结构或注意事项，而不是直接模仿原文。
