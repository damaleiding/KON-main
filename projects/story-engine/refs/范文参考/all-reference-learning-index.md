# 范文学习总索引

## 使用顺序

1. 先读本文件确认目标文本和边界。
2. 再读目标文件夹的 `analysis/structure-study.md`。
3. 若是短中篇，继续读 `analysis/segment-map.md`。
4. 若是长篇，继续读 `analysis/chapter-map.md`、`analysis/volume-scene-map.md` 或 `analysis/long-form-techniques.md`。
5. 只有在确有必要时，才最小范围读取 `licensed-texts/` 中的原文。

新增长篇范文时，先执行工作区 `methods/longform-reference-analysis-workflow.md`；可用本机 skill `longform-reference-analysis` 自动生成目录、结构盘点和地图骨架。

## 已完成定义

- 原文已移动到对应文件夹的 `licensed-texts/`。
- `licensed-texts/` 内有本地使用声明和 `.gitignore`。
- 每个文本至少有 `analysis/structure-study.md`。
- 无稳定章标题的文本有 `analysis/segment-map.md`。
- 长篇文本有章节/篇章地图和专项技法总结。
- 敏感文本的分析只保留结构层抽象，不保留具体桥段。

## 可复用检查表

### 短中篇

1. 开篇前 10% 是否已经建立明确压力？
2. 中段是否至少有一次主动权或关系状态变化？
3. 对话是否推动行动，而不是只重复情绪？
4. 结尾是否固定了一个新状态或余波？
5. 敏感文本是否只抽结构，不迁移具体桥段？

### 长篇

1. 本章继承了上一章的哪个信息、限制或情绪后果？
2. 本章是否产生一个可验证事实、一个可执行行动或一个不可逆关系变化？
3. 阶段成功是否留下新的资源消耗、误判修正或风险窗口？
4. 章节钩子是否能直接转化为下一章动作？
5. 是否有账本记录地标、物件、口令、资源、风险和承诺？
