# 基于公开信息的初步结构观察

这些观察只来自公开简介、书目信息和读者评论，不等同于全文分析。拿到合法全文后需要逐章核验。

## 系列关系

《黄泉引路人》系列可先按以下顺序理解：

1. 《断龙台》：现代商业大厦中的封闭空间怪异事件。
2. 《邪兵谱》：上一部事件两年后，主角宇文树学进入大学校园，围绕邪兵出世展开新一轮危机。
3. 《碎丹青》：公开资料多称为计划中的第三部或终结篇，暂未见完整正式版本。

## 《断龙台》的结构启发

公开简介显示，《断龙台》使用的是“日常空间逐步异常化”的开局方式：

- 起点不是架空玄幻场，而是普通写字楼。
- 新任行政主管顾青提供进入场景的视角。
- 连续怪事和惨案逐步改变空间属性，让办公楼从日常场景变成危机容器。
- 宇文树学以普通职员身份潜伏，后续揭示真实身份，承担世界观解释和行动推进。
- 刑警刘天明提供现实调查线，让超自然事件和现实执法逻辑相互校验。
- 群像角色分布在公司结构中，适合制造嫌疑、遮蔽、利益冲突和阶段性误导。

可学习点：

- 先固定一个强场景，再让异常事件反复撞击这个场景。
- 用“新进入者”承接读者视角，用“隐身专家”承接世界观揭示。
- 章节之间不只靠悬念衔接，也靠现场后果衔接：伤亡、调查、恐惧扩散、角色关系变化。
- 现代职场身份可以作为超自然设定的缓冲层，避免开局直接解释大设定。

## 《邪兵谱》的结构启发

公开简介显示，《邪兵谱》不是简单重复第一部大厦事件，而是采用“时间跳跃 + 场景替换 + 旧主角携带创伤进入新事件”的续作方式：

- 时间上承接《断龙台》事件两年后。
- 宇文树学离开旧城市和旧关系，形成情感空缺。
- 新场景换成大学校园，日常秩序更适合对照“邪兵出世”的破坏力。
- 危机触发点是有人误触秘门，属于“局外人先动手，主角来晚一步”的结构。
- 邪兵争夺引入多方势力，扩大世界观和冲突规模。

可学习点：

- 系列续作可以保留主角和前作伤痕，但换掉场景与事件机制。
- “主角来晚一步”能天然制造前期损失，让故事不必从零铺垫危险。
- 道具或器物体系适合中长篇：每件器物既是章节目标，也是世界观碎片。
- 上一部事件的后果不必反复复述，可以转化为主角的行动选择、回避关系和情感重量。

## 对本项目的参考方向

后续分析时重点看四类衔接：

1. 场景衔接：一个固定空间如何在每章被重新解释。
2. 后果衔接：上一章造成的伤亡、发现、误判和情绪是否进入下一章。
3. 信息衔接：设定不是一次讲完，而是跟随事件逐段解锁。
4. 人物衔接：人物关系变化是否成为下一段行动的理由，而不是只作为情绪装饰。

适合迁移到我们项目的写作规则：

- 章节结尾尽量留下具体未解决状态，而不是抽象总结。
- 下一章开头先处理现场后果，再推进新事件。
- 设定解释要绑定物件、人物行为或危机现场。
- 中长篇主线可以用“强场景 + 连续异常 + 逐步揭底 + 多方势力进入”组织。
- 系列续作或分支重写时，不照搬上一部结构，优先保留人物后果，再换场景和事件机制。
