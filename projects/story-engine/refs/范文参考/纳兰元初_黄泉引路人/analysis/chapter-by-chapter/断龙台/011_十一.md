# 《断龙台》十一学习

## 本单元功能

这一节处理小张死亡后的现实后果，把警方线从调查推进到创伤。

它完成四个推进：

1. 大厦再次封锁，说明死亡事件没有结束。
2. 顾青获得公司车辆，为后续行动提供移动资源。
3. 刘天明复述夜间惨案，让顾青、宇文和警方线坐到同一张桌前。
4. 小张母亲出现，让死亡从案件数字变成亲属痛苦。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 大厦再次被警方封锁，公司人员无法进入 | 公共秩序再度被破坏 |
| 2 | 顾青安排公司资料和车辆 | 现实工作线转为行动资源线 |
| 3 | 她联系刘天明，听出警方内部混乱 | 死亡后果已经撕裂调查系统 |
| 4 | 顾青到警局，看到受伤的宇文和失控后的刘天明 | 三人被惨案重新聚合 |
| 5 | 刘天明讲述小张和王飞遇害经过 | 夜间行动的代价被正式确认 |
| 6 | 宇文提出夜间宵禁建议 | 专家开始给出现实可执行规则 |
| 7 | 刘天明因宇文早知危险而愤怒 | 信任冲突升级 |
| 8 | 宇文被释放，但刘天明留下联系方式 | 现实系统暂时放手，仍保留审视 |
| 9 | 小张母亲冲入警局责打刘天明 | 把职业责任转化为私人痛苦 |

## 承接上一节

上一节以小张死亡和刘天明殴打宇文收束。本节没有跳过后果，而是让所有人坐下来面对：谁死了，怎么死的，为什么没有阻止。

这种承接让死亡有重量，也让刘天明的失控变得可以理解。

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 大厦夜间极度危险 | 宇文提出宵禁 | 专家建议开始进入现实管理 |
| 宇文仍隐瞒真相 | 他知道危险但不完整解释 | 神秘角色的秘密制造道德压力 |
| 刘天明和小张关系深 | 小张母亲的责打和哭诉 | 配角死亡牵出人物关系 |
| 顾青获得车 | 陈词交出公司车钥匙 | 后续行动资源提前配置 |

## 章尾钩子

章尾是小张母亲责打刘天明，顾青理解他为何失控。

这一钩子把案件压力转成情感压力：刘天明不再只是刑警队长，他也背着对死者家属的亏欠。

## 技法提炼

- 死亡后必须写亲属、同事或责任人的反应，否则代价会变轻。
- 行动资源可以在现实琐事中自然发放，例如车钥匙、电话、名片。
- 专家提出规则时，最好让现实人物不完全接受，冲突才有张力。

## 对 KVA 的写作提醒

- 牺牲角色要有后果清算场。
- 调查团队内部情绪会影响后续判断。
- 现实资源的获得要有来源，不能凭空出现。

## 下一单元学习重点
