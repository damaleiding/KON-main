# 《断龙台》十二学习

## 本单元功能

这一节让怪物线正面显形，故事从“可能有鬼怪”推进到“确实有非人实体”。

它完成四个推进：

1. 顾青短暂收留受伤宇文，关系进入私人空间。
2. 刘天明以尸检和现场异常重新联系顾青，现实调查开始触碰超常边界。
3. “蓝月”作为血字再次出现，成为案件核心关键词。
4. 猰狳袭击顾青，宇文和玄罡救场，首次正面对抗上古魔兽。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 顾青带宇文和玄罡回宿舍，给他处理伤口和衣物 | 信任进入私人空间 |
| 2 | 宇文醒后离开，只留下便笺 | 专家保持独自行动习惯 |
| 3 | 刘天明请顾青到大厦协助确认信息 | 现实调查线再次召唤主角 |
| 4 | 刘天明说明血字“蓝月”和尸检异常 | 人类凶杀解释开始失效 |
| 5 | 顾青提醒九点后必须离开 | 宇文规则开始影响现实行动 |
| 6 | 顾青独自驾车离开时遭遇怪物袭击 | 危险从楼内追到车内/停车场 |
| 7 | 宇文和玄罡赶到并击杀怪物 | 专家能力第一次正面展示 |
| 8 | 宇文解释怪物名称和性质 | 世界观从暗示进入明说 |

## 承接上一节

上一节宇文提出夜间宵禁，本节顾青在晚上接近大厦，马上感到这个规则的重要。宇文的提醒不再只是神秘警告，而成为实际保命规则。

同时，刘天明的现实证据也逼近非人解释：尸检、现场文字、力量痕迹都不再能被普通罪案完全覆盖。

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 蓝月会主动留下现场痕迹 | 血字晚于首次勘查出现 | 关键词变成主动挑衅 |
| 凶手不完全像人类 | 尸检和动物学分析 | 现实科学先碰壁，再容纳超常 |
| 顾青已被危险锁定 | 怪物袭击她而非随机路人 | 主角与事件的绑定加深 |
| 宇文有战斗能力 | 虚灵火、玄罡配合、近身制服 | 专家能力用行动展示 |
| 怪物进入命名系统 | 猰狳被解释 | 世界观名词在战斗后出现，更容易接受 |

## 章尾钩子

章尾是宇文说出怪物身份。

它留下的问题：

- 大厦里为什么会出现上古魔兽？
- 蓝月和猰狳是什么关系？
- 还有没有别的怪物？
- 顾青为什么被袭击？

## 技法提炼

- 世界观名词最好在读者亲眼见过现象后出现。
- 科学/刑侦解释先走到边界，超常解释才有重量。
- 第一次正面对抗要让专家赢，但不能让危机显得结束。
- 主角受伤能把“看见怪物”转成“被怪物改变身体状态”。

## 对 KVA 的写作提醒

- 怪物首次实体化前，要用证据链铺路。
- 命名不要早于体验。
- 主角被卷入应有明确身体代价。
- 专家救场后要立刻抛出更大问题。
