
# 《断龙台》三十四学习

## 本单元功能

这一节是题眼前的调查桥。它把宋巧稚、蒲远、平面图和建筑设计院串成一条现实调查路径，最终引出“断龙台”。

## 场景拆解

| 场景 | 表层内容 | 结构作用 |
| --- | --- | --- |
| 1 | 刘天明闯进病房，带来宋巧稚照片线 | 医院缓冲被调查突破打断 |
| 2 | 三人讨论宋巧稚失踪与蒲远隐瞒 | 私密照片转成案件假设 |
| 3 | 顾青调取大厦平面图 | 行政权限再次服务调查 |
| 4 | 宇文发现图纸与现有大厦结构不符，辨认八卦设计 | 建筑线与术法线合流 |
| 5 | 设计院署名魏仁朝出现 | 调查路径从公司转向外部历史知情人 |
| 6 | 顾青和刘天明前往郊外寻找魏仁朝 | 从城市现代空间切到传统/乡土空间 |
| 7 | 魏仁朝认出他们为腾龙大厦而来 | 高人/知情人正式入场 |
| 8 | 魏仁朝说出腾龙大厦所在即断龙台 | 全书题眼落地 |

## 承接上一节

上一节情感线停在“等一切结束”。本节立刻把“结束”需要解决的核心谜题推进一步：宋巧稚不只是私情，她可能与大厦隐秘结构有关。

## 信息释放

| 信息 | 释放方式 | 学习点 |
| --- | --- | --- |
| 宋巧稚可能失踪 | 刘天明从档案和照片推断 | 私情线转案件线 |
| 蒲远隐瞒更多 | 相框照片和封锁现场 | 权力人物秘密深化 |
| 平面图异常 | 图纸与现楼不同 | 空间结构成为关键证据 |
| 大厦设计含八卦逻辑 | 宇文辨认 | 建筑不再只是背景 |
| 魏仁朝知道根源 | 郊外拜访 | 历史真相需要外部老人打开 |

## 章尾钩子

章尾是“断龙台”三个字被说出。

这是点题钩子：读者终于知道书名不是意象，而是大厦所在之地和历史怨气的核心。

## 技法提炼

- 中后段题眼出现前，要用现实证据链逐步引到历史。
- 平面图、署名、设计院这种普通材料，可以打开神秘真相。
- 老知情人登场前，要让主角先带着具体问题去找。

## 对 KVA 的写作提醒

- 书名/卷名题眼不要太早解释，最好在中后段由调查自然推出。
- 现代建筑问题可以连接古代地脉/历史冤案。
- 外部知情人的信息要由主角行动换来。

## 下一单元学习重点
