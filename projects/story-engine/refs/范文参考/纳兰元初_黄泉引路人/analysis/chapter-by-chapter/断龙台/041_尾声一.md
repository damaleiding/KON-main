# 《断龙台》尾声一学习

## 本单元功能

尾声一用顾青写给宇文的信清算事件后果，把终局后的现实烂摊子一项项落地。

## 场景拆解

| 内容 | 结构作用 |
| --- | --- |
| 顾青写信给宇文 | 用第二人称形成余情和缺席感 |
| 腾龙大厦准备重建 | 空间后果被处理 |
| 魏家父子参与新设计 | 历史守护转化为现代重建 |
| 陈词日记被发现 | 隐藏术者线获得事后解释 |
| 陈词散财/公益愿望出现 | 反派复杂化，不只恶化 |
| 钱款归还和公益建议 | 公司经济线完成现实清算 |
| 宇文不回信 | 情感余白保留 |

## 承接最终章

最终章以宇文离开和留下信结束，尾声一改由顾青写信。这个对称很重要：一个人留下信离开，另一个人在后果中继续写信。

## 技法提炼

- 尾声可以换成书信体，快速处理多条后果。
- 反派日记能补充动机，但不应洗白行为。
- 重建、归还、公益这些具体动作，比“大家继续生活”更有重量。

## 对 KVA 的写作提醒

- 大事件后要处理建筑、钱款、人员和组织后果。
- 书信体适合表达“对方缺席但仍被说话”的关系。
- 复杂反派可在尾声补一层人性，但不能取消责任。

## 下一单元学习重点

尾声二要观察：宋巧稚的养父母、刘天影和续作影子如何让系列继续有回声。
