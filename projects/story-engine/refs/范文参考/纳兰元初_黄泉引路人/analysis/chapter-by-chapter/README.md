# 章节级学习索引

本目录用于按章节/场景单元逐步学习《断龙台》《邪兵谱》的写法。

## 学习规则

- 一次只拆一个章节或一个场景段。
- 不复制长原文，只记录结构功能、承接方式、信息释放、章尾钩子和可迁移技法。
- 每个单元都回答：它从哪里接来、在本章推进什么、给下一章留下什么。
- 学习结论优先转成可执行规则，服务 KVA 的三章规划、续写、润色和章节自检。

## 目录

- `断龙台/`：按《断龙台》引子、一、二……尾声逐单元拆解。
- `邪兵谱/`：后续按 43 个场景段逐段拆解。
- `final-learning-synthesis.md`：两本书逐章学习后的总工法和 KVA 迁移规则。
