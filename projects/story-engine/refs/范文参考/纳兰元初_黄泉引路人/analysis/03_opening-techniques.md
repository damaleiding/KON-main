# 第一阶段：开篇与衔接技法

## 核心结论

这两本书的开篇都不是从宏大设定开始，而是从非常具体、可感的日常空间开始，然后逐层让日常空间失去安全感。

《断龙台》选择商业大厦，《邪兵谱》选择大学校园。两者共同点是：空间本身先可信，异常才有重量。

## 《断龙台》的开篇机制

1. 先用感官污染建立场景气味和质地。
2. 用电梯和楼层按钮制造空间异常。
3. 切到顾青进入大厦，让读者从“异常先兆”进入“正常上班”。
4. 让宇文树学以非专家身份出现，先产生误认和轻松互动。
5. 在开窗、细微声响和宇文反应中塞入第二次异常，形成“刚刚的怪事不是偶然”的连续感。

可学习点：

- 开篇异常不必大声，关键是要落在具体物件上。
- 第一章最好让角色真实地处理一个小问题，异常借小问题露出来。
- 专家角色可以先伪装成普通人，这样设定解释会更晚、更自然。

## 《邪兵谱》的开篇机制

1. 先给题记式古文，建立器物和古意。
2. 马上落入校园卫生间和课堂，避免长期停留在抽象古典气氛里。
3. 唐考在卫生间与宇文第一次相遇，形成“奇怪的人”印象。
4. 课堂上宇文通过讲古，把历史、野史、灵异、器物和人物魅力揉在一起。
5. 读者先接受“这个老师讲故事厉害”，再接受“这些故事可能是真的”。

可学习点：

- 历史设定可以藏进角色的讲述能力，不要单独做设定说明。
- 课堂/讲述场景本身可以成为世界观导入工具，但必须同时服务人物关系。
- 一段传说最好最后接回现实人物的眼神、态度或行动，让故事从“知识”变回“剧情”。

## 两本共同的上下文衔接方式

| 衔接类型 | 做法 | 效果 |
| --- | --- | --- |
| 空间衔接 | 先固定大厦/校园，再持续返回同一空间 | 读者不会在设定扩大时迷路 |
| 物件衔接 | 电梯、窗锁、古琴、长刀、法阵等物件反复出现 | 把设定变成可触摸的线索 |
| 误认衔接 | 顾青误认宇文身份，学生误判宇文老师 | 让人物关系自然建立，不靠介绍 |
| 知识衔接 | 历史、野史、器物传说逐步进入 | 设定有来源感，不像凭空解释 |
| 异常递进 | 先小异常，再让角色反应暴露严重性 | 悬疑感来自角色感知，而不是旁白宣告 |

## 可以迁移到我们项目的规则

- 章节开头优先处理上一章留下的具体现场、物件或身体状态。
- 新设定要绑定角色正在处理的小问题，不单独讲说明书。
- 每个大场景要有可反复调用的物件系统，作为章节之间的钩子。
- 关键人物初登场可以通过误认、遮蔽和小互动建立，而不是直接给身份标签。
- 中长篇开局先给一个可信日常，再逐步让日常空间变质。
