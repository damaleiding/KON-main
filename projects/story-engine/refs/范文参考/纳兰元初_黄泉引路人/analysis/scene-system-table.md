# 场景系统表

## 《断龙台》：封闭高楼系统

| 场景 | 初始功能 | 被污染后的功能 | 反复使用方式 |
| --- | --- | --- | --- |
| 电梯 | 普通通勤工具 | 楼层错位、12楼异常、运输尸体/怪物想象、行动限制 | 每次返回电梯，危险等级都会提高 |
| 18楼办公室 | 顾青工作场所 | 书架、珠串、窗口女人、案发现场 | 现实工作目标和超自然线索重叠 |
| 12楼 | 无人招租楼层 | 黑暗女人、空间异常、未知中转点 | 先作为视觉恐惧，再成为结构谜题 |
| 大厦大厅/宴会厅 | 公司形象展示场 | 酒会设局、最终对峙 | 社交空间转化为战场 |
| 医院/街头/面馆 | 外部缓冲区 | 恢复体力、建立信任、交换信息 | 高压场景后用日常空间沉淀人物关系 |
| 控制室/监控系统 | 现代管理工具 | 对抗和设局工具 | 让现实技术与术法危机协同 |

《断龙台》的场景系统特点：

- 强封闭：大厦是主容器，所有外部线索最终都要回到大厦。
- 强垂直：楼层、楼梯、电梯让空间天然有方向感。
- 强物件：按钮、窗锁、书架、珠串、监控、宴会设备都是钩子。
- 强后果：场景一旦出事，下一次返回时读者会记得上一次的伤亡和恐惧。

## 《邪兵谱》：开放校园网络

| 场景 | 初始功能 | 被污染后的功能 | 反复使用方式 |
| --- | --- | --- | --- |
| 教室 | 讲课、师生关系 | 历史故事和器物设定入口 | 用课堂讲述把知识变剧情 |
| 卫生间/宿舍 | 学生日常 | 初遇、私密情绪、低烈度异常 | 让奇怪人物先从日常角落出现 |
| 工地 | 校园边缘施工空间 | 失踪、邪兵、夜战、终局前置空间 | 作为校园秩序外的危险边界 |
| 礼堂 | 公共活动场 | 血案爆发、公共恐慌 | 让危机从小圈子扩散到全校 |
| 运动场/校运会 | 青春日常和群体活动 | 追踪、证据传递、群众遮蔽 | 用人群制造传递信息的难度 |
| 博物馆/资料场 | 知识场 | 器物史和跨文化线索 | 把历史源流具体化 |
| 临时厂房 | 施工附属空间 | 长刀重铸、法阵、终局 | 开放校园最后收束到临时封闭场 |

《邪兵谱》的场景系统特点：

- 开放网状：没有单一大厦，靠多个校园节点组成网络。
- 群体密集：同学、老师、学生会、运动会让信息传播和遮蔽同时发生。
- 边界空间重要：工地、厂房、树林承担危险升级。
- 知识场景多：课堂、博物馆、素描、历史讲述都在输送世界观。

## 对我们项目的迁移规则

- 如果故事需要强悬疑，优先设计一个“可反复返回、每次意义改变”的场景。
- 如果故事是开放空间，必须给空间节点分配不同功能：日常、线索、危险、情绪、终局。
- 场景钩子要物件化，不要只靠“气氛很诡异”。
- 章节衔接时，下一章开头可以换地点，但要承接上一章留下的物件、伤口、证据或人物状态。
