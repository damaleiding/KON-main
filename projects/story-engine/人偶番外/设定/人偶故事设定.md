# 人偶故事设定与创作指南

本文档整理了《人偶》系列故事的核心世界观、写作风格、整体基调以及特殊的文字要求。在进行大纲设计、角色创作、正文续写及番外拓展时，必须严格参考本文档及《角色卡.md》中的设定。

---

## 一、 世界观设定

### 1. 核心灾变背景
- **第二次侵蚀事件**：二十三年前全球同步爆发的无征兆灾变。侵蚀质弥漫，诱导生物基因不可逆畸变（产生畸变体），人类长期暴露会导致基因崩解死亡或失智。
- **繁华都市孤岛**：人类文明并未覆灭，旧时代跨国体系瓦解后，幸存者依托超大型都市圈建立起隔离屏障与净水系统。城市内部摩天楼宇林立，商业、民生运转正常（甚至比现代更发达），仅多出了侵蚀质监测和严格的出入管控。
- **非废土设定**：世界格局是“繁华都市孤岛环绕未知禁区”，城市外围是隔离带，再往外才是侵蚀区。**绝非全域废土**，城市内的生活充满现代科技感与生物技术感。

### 2. 核心“人形”体系
- **活体人类基底**：所有人形均以活体人类为**唯一基底**，通过基因编辑、神经强化、骨骼与脏器义体化改造而成。**绝对不是AI机器人或纯机械生命**，保留了完整的人类意识与情感。
- **人形的定义**：骨骼与脏器义体化达20%以上即被归为人形。这是一种“人造的族裔”，占据联邦总人口约10%。他们没有明显的外在机械标识，唯一的身份证明是身份证上的“联邦统一编码”。
- **风险与困境**：改造不可逆，伴随终身排异、神经损伤风险，必须定期服用抑制剂。由于改造异化及潜在失控风险，人形在社会上受到普通市民排斥和官方严格管制。

### 3. 全球核心势力格局
*（注：这些巨头如同现实中的跨国企业与国家机器，主角只是其中的细胞，设定应通过文件标签、新闻公告、侧面事件自然带出，切忌在正文中进行长篇大论的解说。）*
- **新联邦政府**：最大主权主体，掌控核心城市群。对内推行严苛的人形管制法案，对外负责隔离带管控。内部派系林立，腐败丛生。
- **军工复合体集团**：垄断全球80%义体与军械的资本巨头，联邦的技术基石。唯利是图，暗中向各方输送违禁技术。
- **安可生命集团（安可医疗）**：规模最大的医疗巨头，拥有顶尖的人形修复与克隆技术。明面上是正规医疗，暗地里（如主角的诊所）从事克隆体制造、器官倒卖、黑市救治与违禁改造。
- **财联合会**：以安可医疗等十三个大企业为核心的商业联盟，掌控灰色物流与地下交易，势力可抗衡联邦与军方。
- **远东赤骸革命军 / H604研究所**：前者为被抛弃人形组成的极端反叛武装，后者为隐秘的极端人体实验机构（潜藏在繁华之下的阴影）。

### 4. 主视角阵营与核心舞台
- **维特鲁威诊所**：位于B5地区商业区与贫民区交界处（高低落差30米物理分割）。
- **达芬奇**：诊所所长，安可医疗末端的黑手套。明面全科医生，暗地是疯狂的血肉艺术家，用克隆体及自愿活体制造顶级“人偶（性玩具）”。
- **核心舞台**：灯火通明的诊疗室、阴暗的地下黑市、精英营地。极少深入荒野侵蚀区。

## 二、 整体基调

### 1. 核心叙事基调
- **近未来都市生物科技风**：社会背景类似于《少女前线》或《胜利女神：Nikke》。科技极其发达，人类正在努力重建文明。**不要把赛博朋克味写得过重**，避免滥用赛博黑话和过度颓废的底层赛博景观。
- **灰色地带的日常**：故事重心放在都市阴影中的诊所日常、人形患者的隐秘委托上。通过个案推动主线，在光鲜与阴暗的交界处展现人性挣扎。

### 2. 官能小说的极致聚焦
- **情色与感官刺激为主轴**：本书的绝对核心是**官能小说**。剧情推进必须聚焦于各个人偶角色的感官刺激、被玩弄的过程，以及阿真、小幽等执行者令人面红耳赤的工作/维护日常。
- **受虐癖与反差痴女内核**：登场的人偶角色（如骁、岚、妮娅、芮、伊莎贝拉夫人），除了其社会身份与过去的矛盾外，**接受改造的核心动机必须包含极强的“隐性/显性自愿系痴女”属性与极端的受虐、自毁倾向**。她们享受那种社会高阶身份与底层肉便器身份的极致反差。

## 三、 写作风格

### 1. 色色的轻小说文风
- **克制与反差**：文风偏向日系轻小说。在日常互动中保持语言的克制与日常感，不使用“毁灭性”、“狂暴”、“撕心裂肺”、“逻辑死火”等沉重、猎奇、夸张的形容词。
- **细腻的色气感**：痛楚与快感的描写应转化为“酥麻”、“战栗”、“大脑空白”、“呼吸停滞”等充满色气与羞耻感的轻小说式表达，避免写成纯粹的血腥虐杀。

### 2. 重情节的详细肉戏
- **拒绝空泛堆砌**：不要用大量无意义的形容词去概括性爱场景。
- **细节拉长张力**：通过具体的动作细节（如缓慢的摩擦、器具拔出时的粘稠声）、角色的心理挣扎（双重视角下的羞耻感）、以及淫靡下流的对话交锋来拉长肉戏情节，让过程充满张力。

## 四、 特别的文字与描写要求

### 1. 绝对禁止“宗教感”词汇
- **严禁使用**：文章中**绝不能出现**带有强烈宗教崇拜色彩的词语，如“圣像”、“献祭”、“血肉工程”、“圣殿”、“洗礼”等。
- 改造是出于生物科技、权力支配以及角色自身的病态性欲与自毁倾向，而不是虚无缥缈的邪典崇拜。

### 2. 不避讳露骨的器官名词
- 在描写肉戏或医学改造时，**必须直接、大胆地使用露骨词汇**（如“阴道”、“肉穴”、“乳头”、“子宫”、“前列腺”等），绝对不要自我审查或使用隐晦的比喻。

### 3. 避免冗长的设定说明
- 遇到世界观、道具、改造原理等设定时，**严禁长篇大论的旁白解说**。必须通过角色的动作（如透视扫描、日常维护）、情节的推进或对话的侧面交锋自然带出。

### 4. 章节字数与格式要求
- **独立统计**：如果章节被拆分为上、中、下等独立部分，**字数统计必须直接紧跟在每个独立部分的最后一行之后**。
- 格式规范：
  ```markdown
  # 本章字数统计
  - 上半章正文：约 xxxx 字
  ```
