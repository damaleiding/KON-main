# 长篇生成规则

## 目标

本文件把长篇范文学习沉淀为 Story Engine 的生成规则。它用于章节续写、章节重写、三章规划、分支试写和生成后自检，重点保证上下文连续、状态可继承、剧情不空转，并把钩子兑现、配角信息动作、现实义务、时间跳跃和终局清算纳入生成检查。

## 章节接力硬规则

正式写作前必须先写“章节接力卡”。如果缺少上一章上下文，应标注“上下文不足”，不能假装已经承接。

```text
上一章继承状态：
本章开场压力：
本章核心行动：
本章验证物/关键信息：
旧钩子兑现或延期理由：
配角信息动作：
现实义务/后果压力：
环境/物件/身体约束：
人物状态变化：
信息账更新：
资源账更新：
关系账更新：
风险账更新：
方案账更新（生存/技术/任务/调查类可选）：
章尾交付给下一章的钩子：
禁止断裂点：
```

字段说明：

- `上一章继承状态`：上一章留下的信息、限制、情绪后果、伤害、物件、承诺、时间窗口或未完成动作。
- `本章开场压力`：本章前 10% 必须显现的具体压力，不能只写氛围。
- `本章核心行动`：角色本章主动做什么，不能只有被动承受或解释设定。
- `验证物/关键信息`：用于确认、误导或改变判断的地点、物件、记录、对话证词、身体状态或行动结果。
- `旧钩子兑现或延期理由`：上一章留下的可操作状态如何被处理；如果暂不处理，延期本身要产生压力、代价或误判。
- `配角信息动作`：非主角承担的发现、传递、误判、验证、遮掩、救援、背叛或后果动作。
- `现实义务/后果压力`：工作、学校、家庭、组织、法律、金钱、身体恢复或社会关系如何继续影响本章选择。
- `环境/物件/身体约束`：被强调的天气、地点、制度、物件、伤害或身体状态如何改变行动条件。
- `人物状态变化`：至少记录一个人物的判断、关系、主动权、秘密、依赖、恐惧或欲望变化。
- `四账本更新`：信息、资源、关系、风险至少一项必须变化；长篇重点章节应多项变化。
- `方案账更新`：生存、技术、任务和调查类章节记录哪些方案可行、不可行或部分可行，以及下一章选择如何变窄。
- `章尾钩子`：必须能转化为下一章开场动作，不只是一句抽象悬念。
- `禁止断裂点`：明确本章不能忘记的设定、上一章动作、关系状态或伏笔。

## 钩子兑现规则

- 旧钩子优先于新钩子。本章前半段应优先处理上一章末尾留下的物件、承诺、误会、伤害、规则、行动安排或信息缺口。
- 如果旧钩子暂不兑现，必须在章节接力卡或生成说明中写明延期理由，并让延期本身增加压力、代价或误判。
- 新钩子不能凭空另起，最好继承旧钩子的验证结果、行动后果或关系变化。
- 每个钩子应有可操作形态：谁要做什么、去哪里、验证什么、等待什么、隐瞒什么或承担什么后果。

## 场景推进规则

- 每个主要场景至少改变一类状态：行动、信息、资源、关系、风险、位置、身体状态或心理主动权。
- 场景不能只承担“展示设定”“加强氛围”“铺垫情绪”。如果没有状态变化，应合并、缩短或改成有后果的动作。
- 长段扩写必须增加动作链、阻碍、互动、选择、误判、物件变化或小后果，不得靠景物和抽象心理灌水。
- 对话必须有功能：试探、误认、确认、交换信息、威胁、协商、触发行动、改变关系或转场。

## 配角与现实义务规则

- 长篇不能让主角独自完成所有发现、判断和救场。每 1 到 3 章至少安排一个配角承担不可替代的信息动作：发现、传递、误判、验证、遮掩、救援、背叛或承担后果。
- 判断配角是否有效：如果删掉该配角，线索链、行动链或关系后果应明显断裂。
- 异常、危机或感情推进不能让现实义务消失。工作、学校、家庭、组织、法律、金钱、身体恢复和社会关系应继续提供阻力或资源。
- 大事件之后要写后果账：身体、法律、组织、金钱、名誉、亲密关系或心理状态至少一项进入后续章节。

## 问题链规则

悬疑、任务、技术线和关系线都应形成问题链：

```text
疑问 -> 误判/阻碍 -> 验证 -> 代价 -> 新疑问
```

使用要求：

- 新谜题最好继承旧谜题的验证结果，而不是凭空另起。
- 验证不能总是口头解释，优先用物件、地点、记录、行动和后果。
- 失败也要推进：失败必须产生新知识、排除路径、暴露边界或改变关系。

## 设定解释规则

- 解释只能解释够当前行动使用的部分。不要在单章中把世界观、组织结构、规则体系一次讲完。
- 好解释应同时解决一个低层疑问，并留下一个更高层疑点、行动压力或关系后果。
- 世界观名词最好在读者已经看见现象、证据或后果后出现；规则说明要落到角色能执行的方案。
- 问答场景要有攻防变化。提问、回避、承认、反问、误导和交换条件应改变双方位置，而不只是信息倾倒。

## 四账本规则

每章生成后检查四账本：

| 账本 | 记录什么 | 不合格表现 |
| --- | --- | --- |
| 信息账 | 新知道、误判、隐瞒、验证、口令、线索 | 只有情绪，没有新信息或判断变化 |
| 资源账 | 时间、体力、金钱、道具、机会、伤害、环境限制 | 危机解决后状态复原，没有代价 |
| 关系账 | 信任、依赖、敌意、羞耻、承诺、把柄、权力 | 人物关系停在同一状态 |
| 风险账 | 追捕、暴露、期限、误会、伤害、规则收紧 | 章尾没有下一章压力 |

生存、技术、任务和调查类章节可增加 `方案账`：记录哪些方案可行、不可行或部分可行，以及下一章选择因此如何变窄。失败章节如果没有方案账更新，通常说明失败没有推进剧情。

## 多线叙事规则

- 双线或多线不是简单换视角，而是信息交接。
- 每次切线要明确：谁发送信息、谁接收信息、如何验证、验证后改变什么行动。
- 如果一条线连续两次没有改变另一条线的行动或判断，应暂停、合并或改写。

## 时间跳跃与缓冲规则

- 时间跳跃不能制造空白。跳过几小时、几天或几周后，要交代谁在暗中行动，产生了什么成果、误判、伤害、资源变化或风险升级。
- 静默期结束时必须出现可见成果：物件移动、关系变化、方案进展、监视结果、组织介入或新限制。
- 大事件后允许低声部缓冲场，但缓冲场必须推进关系、信息、伤害后果或下一步准备，不能只休息和抒情。
- 轻松、日常和幽默可以作为节奏阀，但应服务人物关系、现实义务或压力反差。

## 环境与物件规则

- 被强调的天气、地点、建筑、制度、身体状态或物件必须规则化，至少影响一次行动条件、风险判断或后续选择。
- 关键地标和物件要进入连续性账本，反复承担验证、记忆、危险、承诺、误导或路线功能。
- 梦境、幻觉、回忆或异常感知之后，最好留下现实痕迹，如伤痕、物件变化、记录缺口、第三方反应或行动后果。

## 章尾规则

- 章尾优先落在具体状态：未完成动作、物件、声音、位置变化、身体反应、决定、误会、风险窗口或下一步约定。
- 不用总结、宣告、升华或“从此改变”式旁白收束。
- 阶段成功也必须留下代价；阶段失败必须留下新知识。

## 终局清算规则

- 进入终局或阶段终局前，先列出未清算线索：物件、承诺、误会、人物债、风险窗口、规则例外和早期异常。
- 每条线索至少得到一种处理：结论、代价、余波、转交到下一阶段，或明确标记为暂不清算。
- 终局不是只写“打赢”或“关系确认”，还要清算旧线索、旧代价和旧承诺。
- 终局后如果保留续作空间，应留下具体余波，而不是抽象宣告。

## 生成后自检

1. 本章是否继承上一章至少一个具体状态？
2. 本章是否产生下一章能接住的新状态？
3. 每个主要场景是否改变行动、信息、资源、关系或风险？
4. 对话是否推动动作或改变关系？
5. 本章是否更新四账本至少一项？
6. 章尾钩子是否能直接转成下一章开场动作？
7. 是否存在靠解释设定、抽象心理、景物堆叠或同义反复凑长度的问题？
8. 上一章旧钩子是否被兑现、推进或明确延期？
9. 是否有配角承担不可替代的信息动作或后果动作？
10. 设定解释是否只解释够当前行动使用，并留下行动压力或更高层疑点？
11. 如果有时间跳跃或缓冲场，跳过时间里是否有人行动，缓冲场是否推进了信息、关系或准备？
12. 被强调的环境、物件或身体状态是否进入行动条件、风险账或资源账？
13. 如果接近终局，未清算线索是否有结论、代价、余波或延期标记？
