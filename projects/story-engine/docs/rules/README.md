# Story Engine 规则索引

本目录保存 Story Engine 的生成层规则。规则已迁入本项目；旧项目规则目录仅作为历史归档/回滚入口。

## 当前文件

- `canvas-bridge-contract.md`：Story Canvas 向 Story Engine 交接生成请求的字段契约。
- `longform-generation.md`：长篇生成规则。
- `reference-learning-application.md`：范文学习成果如何转成生成规则、prompt 和自检问题。
- `chapter-planning.md`：三章剧情单元、章节长度、主线/分线和写作前规划规则。
- `chapter-continuity.md`：章节首尾串联、拆分、合并和检查规则。
- `style-quality.md`：文风质量检查维度。
- `avoidance-lexicon.md`：规避词表字段、维护方式和作品级词表落点。
- `text-organization.md`：原文、设定、主干、分支、发布、输出和临时文件边界。
- `path-and-naming.md`：路径结构、文件命名、各区域生成规则和生成后同步清单。
