# 正文版本备份工作流

## 目的

防止正文在拆分、合并、格式清理、编码修复、润色覆盖或字数统计更新时被误改、乱码化或丢失。

## 备份位置

- 专用备份库：`projects/story-engine/_backups/text-history/`
- 备份目录按作品、分支、章节和时间戳分层。
- 示例：`_backups/text-history/人偶番外/成人化重设/第八章/20260530-223914-before-mojibake-repair/`

## 强制备份场景

以下操作前必须先备份目标文件：

- 覆盖正文文件。
- 拆分、合并或重排章节。
- 格式清理、硬换行修复、编码修复。
- 添加、移除或改正章节末尾字数统计。
- 批量替换、脚本处理或模型辅助改写。
- 人物卡或设定文件中会影响正文连续性的批量修改。

## 操作要求

- 每次备份只复制本次会改动的文件，避免全项目无意义快照。
- 备份文件必须保留原文件名。
- 备份目录必须包含 `manifest.json`，记录源路径、备份时间、操作原因和文件数量。
- 修复乱码时，先备份乱码状态，再执行修复，保证可以追溯修复前后的差异。
- 更新字数统计时，每个正文文件必须只保留一个末尾统计行；流程是先删除旧统计，再重算并追加唯一统计。
- 回退时，从对应时间戳目录复制原文件覆盖当前文件；覆盖前仍需再备份当前状态。

## 推荐命令

```powershell
python "projects\story-engine\tools\scripts\backup-text-version.py" `
  --reason "before-edit" `
  --work "人偶番外" `
  --branch "成人化重设" `
  --chapter "第八章" `
  "projects\story-engine\人偶番外\分支\成人化重设\第八章（成人化重设·上）.md"
```
