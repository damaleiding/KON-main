# 文风质量检查工作流

## 触发场景

- 用户要求检查文风、语气、节奏、对白、设定呈现或“像不像原作品”。
- 章节生成、润色、重写或发布整理后。
- 审稿发现抽象总结、网感词、现代感错位、重复句式或角色声音不稳。

## 必读上下文

1. 目标正文。
2. 目标作品 `设定/风格指南.md`。
3. 目标作品 `设定/故事圣经.md` 和 `设定/当前状态.md`。
4. 出场角色对应人物卡。
5. 如需查词，读取项目或作品规避词表。

## 检查维度

- 叙述视角：人称、距离、信息披露是否稳定。
- 章节节奏：动作、心理、对白、环境描写比例是否贴合作品。
- 角色声音：对白是否符合人物卡和关系状态。
- 设定呈现：是否把设定写成说明书。
- 修辞密度：是否出现过度比喻、排比、总结升华或概念化旁白。
- 词汇习惯：是否命中禁用/慎用词，是否出现与作品时代、场景或角色身份不合的表达。

## 输出格式

```text
结论：通过 / 需调整 / 上下文不足
依据：
- 风格指南：
- 人物卡：
- 用户要求：

问题：
- 位置：
- 类型：
- 说明：
- 建议：

可保留项：
- 说明：

待同步：
- 风格指南：
- 规避词表：
```

## 注意事项

- 风格判断不能只靠词表；词表只负责命中风险，最终仍要结合语境。
- 不把某个作品的风格经验直接硬套到另一个作品。
- 如果缺少风格指南，应先标记上下文缺口，再给临时判断。
